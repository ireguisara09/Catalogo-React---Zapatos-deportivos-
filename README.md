# SNEAKERLAB - Catálogo de Zapatos Deportivos

## Descripción

SNEAKERLAB es una aplicación web desarrollada con React y Vite que permite visualizar un catálogo de zapatos deportivos de diferentes marcas reconocidas.

El proyecto presenta una interfaz moderna y responsive para consultar productos deportivos, visualizar información básica de cada producto y agregarlos a un carrito de compras.

## Objetivo

Desarrollar una aplicación web utilizando React para aplicar conceptos fundamentales del desarrollo frontend, como componentes, props, estados, eventos y renderizado dinámico de listas.

## Funcionalidades

- Página de inicio con sección principal.
- Catálogo de zapatos deportivos.
- Visualización de productos por categorías.
- Productos de diferentes marcas.
- Visualización de precios en pesos colombianos.
- Contador de productos agregados al carrito.
- Función para agregar productos al carrito.
- Diseño responsive para diferentes tamaños de pantalla.
- Componentes reutilizables desarrollados con React.

## Tecnologías utilizadas

- JavaScript
